# About the app

### 🎛️ Two Click Modes
| Mode | Behavior | Best For |
|------|----------|----------|
| **Spam Click** | Continuous click-down/click-up pairs at set interval | Fast clicking, bridge fights, PvP |
| **Hold Button** | Presses and holds the button until stopped | Mining, breaking blocks, continuous actions |

### ⚙️ Customizable Settings
- **Separate Intervals** — Different speeds for left and right clicks (1-10000ms)
- **Configurable Hotkey** — Choose from common function keys (F1-F12, Insert, Delete, etc.)
- **Persistent Config** — All settings saved to `%LOCALAPPDATA%`

### 🔊 Audio & Visual Feedback
- **Start/Stop Sounds** — WAV audio cues for toggle events
- **Status Indicator** — Visual status label with active/inactive states
- **System Tray Support** — Minimize to tray, restore on double-click
- **Emergency Kill Switch** — `Esc + Backspace` instantly stops all clicking

### 🛡️ Safety & Convenience
- **Single Instance Enforcement** — Prevents running multiple copies
- **Control Lockout** — Settings disabled while clicking to prevent mid-session changes
- **Portable** — No installation required, runs from any folder
- **Lightweight** — Minimal CPU usage, efficient background threads
